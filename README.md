Grade 9 – Emergency Signal System

Project Description

The Emergency Signal System is a pushbutton-controlled warning system using an Arduino Uno and a red LED.

Components

- Arduino Uno
- Pushbutton
- Red LED
- 220Ω resistor
- Jumper wires

How It Works

Pushbutton: Acts as the input that activates the emergency signal.

Arduino Uno: Processes the button's state and controls the LED.

Red LED: Serves as the visual warning signal by blinking when the button is pressed.

System Behavior

Button State| LED Status
Pressed| Blinking
Released| OFF

Blink Interval

250 milliseconds ON and 250 milliseconds OFF.
